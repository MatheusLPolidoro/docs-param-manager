A página inicial ganhou os selos do projeto: versão no PyPI, linguagem, cobertura de testes e versões de Python suportadas. O de versões é estático, e não o `pypi/pyversions` — o pacote publicado não declara classificadores de versão, e o selo dinâmico renderiza a palavra "missing". Os selos são a única coisa do site que depende de rede externa para aparecer; sem internet o navegador mostra o texto alternativo de cada um.
