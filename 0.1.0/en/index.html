      Param Manager¶

      Centralized parameters, encrypted secrets, and reads that don't go down¶

      Param Manager takes configuration out of the .env file on every machine and puts it in one versioned, auditable place — without making your application depend on the network being up at the moment it reads.

      The product is two artifacts shipped separately and a contract between them:

      • fast-param-manager — the API A FastAPI server on MongoDB, authenticated through Keycloak. It stores parameters, validates each one's type, encrypts the sensitive ones and decides who may write what.
      • param-manager — the client A Python library published on PyPI. It reads parameters, keeps an in-memory cache, decrypts secrets and keeps answering from local data when the API does not respond.
      • The cryptographic envelope The format a secret is stored in. It is a frozen contract: both sides implement the same thing, in repositories released on different dates.

      What this documentation assumes¶

      That you will read the code when the answer really matters. Every page here was written against the implementation, and where the behaviour is surprising that is stated on the page rather than hidden. When this site and the code disagree, the code is right — and the page has a defect, which is worth reporting.
