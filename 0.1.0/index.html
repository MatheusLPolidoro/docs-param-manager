      Param Manager¶

      Parâmetros centralizados, com segredo cifrado e leitura que não cai¶

      O Param Manager tira a configuração de dentro do .env de cada máquina e a coloca num único lugar, versionado e auditável — sem que a aplicação passe a depender de a rede estar de pé no instante da leitura.

      O produto são dois artefatos entregues separadamente e um contrato entre eles:

      • fast-param-manager — a API Servidor FastAPI sobre MongoDB, autenticado por Keycloak. Guarda os parâmetros, valida o tipo de cada um, cifra os sensíveis e decide quem pode escrever o quê.
      • param-manager — o cliente Biblioteca Python publicada no PyPI. Lê os parâmetros, mantém cache em memória, decifra os segredos e continua respondendo com dado local quando a API não responde.
      • O envelope criptográfico O formato em que um segredo é gravado. É contrato congelado: os dois lados implementam a mesma coisa em repositórios que são liberados em datas diferentes.

      O que esta documentação assume¶

      Que você vai ler o código quando a resposta importar de verdade. Todas as páginas aqui foram escritas conferindo a implementação, e onde o comportamento é surpreendente isso está dito na página em vez de escondido. Quando houver divergência entre o que está escrito aqui e o que o código faz, o código está certo — e a página está com defeito, o que é um problema a ser reportado.
